# Тесты правил ходов

Проверяют правила длинных и коротких нард: расстановку, голову, запрет бить и заграждение из шести (длинные), бар, удары и вход (короткие), выброс, обязательность полного хода и большего кубика. Плюс 40 случайных партий в каждом режиме от начала до конца с проверкой каждого шага.

Запуск из корня репозитория (нужен Node 20+, ничего ставить не надо):

```
node --test tests/*.test.js
```

Правила берутся прямо из `index.html` — блок от `/* ---------- правила ---------- */` до `/* ---------- компьютер ---------- */` и функции `freshState`, `headLim`, `enumerate` (см. `load-rules.js`). Сама игра для тестов не менялась. Если эти метки или имена переименовать, тесты сразу скажут, что поправить в `load-rules.js`.

На GitHub тесты запускаются сами при каждом изменении `index.html` или `tests/` (`.github/workflows/tests.yml`).
